The terminology server

Every query on this site runs against the HSE National Medicinal Product Catalogue, the Irish national terminology server.

HSE National Medicinal Product Catalogue

https://nmpc.hse.ie/production1/fhir
Ireland

The templates on this site cover medicines. The server also carries the SNOMED CT International release, so a custom query can reach beyond the drug model if you need it to.

Its drug model follows the dm+d pattern, with a reference set for each level of the product hierarchy:

  • VTM — Virtual Therapeutic Moiety. The substance, with no strength or form.
  • VMP — Virtual Medicinal Product. Strength and dose form, no brand.
  • VMPP — Virtual Medicinal Product Pack. A generic product in a pack size.
  • AMP — Actual Medicinal Product. A specific branded product.
  • AMPP — Actual Medicinal Product Pack. What a pharmacy actually dispenses.
  • ATM — Actual Therapeutic Moiety. A brand without strength or form.

It also carries Irish extension attributes that do not exist in the international release, including marketing authorisation holder, licensing status, supply legal status, licensed route of administration and product authorisation number.

Signing in

The catalogue requires an HSE-issued client ID and secret. You enter your own from the server button in the toolbar.

  • Stored in your browser only — session storage by default, or on this device if you tick "remember".
  • Sent only to nmpc.hse.ie, and to nothing else.
  • Never reaching this website, which is fully static and has no backend that could receive them.

"Sign out" removes them. On a shared computer, leave "remember on this device" unticked and they are forgotten when you close the tab.

How the queries are sent

Every query becomes a FHIR ValueSet/$expand against an implicit SNOMED CT value set, with a bearer token from the HSE sign-in service:

GET [base]/ValueSet/$expand
    ?url=http://snomed.info/sct?fhir_vs=ecl/[url-encoded ECL]
    &count=100&offset=0&displayLanguage=en
Authorization: Bearer [token]

The expression must be percent-encoded. An unencoded | makes some servers read the rest of the URL as a version and reject the request.

Other countries

This deployment is Ireland only. The server registry in js/servers.js describes each endpoint alongside its drug model, and the query templates are written against that description rather than hard-coded concept IDs — so adding another national server is a configuration change, not a rewrite.
