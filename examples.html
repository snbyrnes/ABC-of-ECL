Examples & Syntax

Every expression opens in the builder, ready to run against the HSE catalogue

Every Virtual Therapeutic Moiety

The substances a prescriber chooses between, with no strength, form or brand attached. The top of the Irish product hierarchy.

^ 660351000220100 |VTM reference set|

Generic paracetamol products

Virtual Medicinal Products containing paracetamol — strength and dose form, but no brand.

^ 660371000220109 |VMP reference set| :
  127489000 |Has active ingredient| =
    << 387517004 |Paracetamol|

Packs of 24

Dispensable packs containing exactly 24 units. Pack size is numeric, so it is matched with # rather than a concept.

^ 660401000220107 |AMPP reference set| :
  1142142004 |Has pack size| = #24

Penicillin-free products

Everything except products containing any penicillin. This is the shape of an allergy exclusion: start with all, subtract what must be avoided.

^ 660371000220109 |VMP reference set|
MINUS
(^ 660371000220109 |VMP reference set| :
  127489000 |Has active ingredient| =
    << 764146007 |Penicillin|)

Products from one manufacturer

Branded products whose marketing authorisation is held by a named company. Marketing authorisation holder is an Irish extension attribute.

^ 660381000220107 |AMP reference set| :
  680061000220102 |Has marketing authorisation holder| =
    253961000220103 |Accord Healthcare Ireland Ltd|

Combination products

Products containing both paracetamol and codeine. Each side of the AND is a complete constraint, so the result is the intersection of the two sets.

(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387517004 |Paracetamol|)
AND
(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387494007 |Codeine|)

Paracetamol at 500 mg

Dose-based prescribing. Strength is a number, so it is matched with # rather than a concept, and the comma means both conditions must hold.

^ 660371000220109 |VMP reference set| :
  127489000 |Has active ingredient| = << 387517004 |Paracetamol|,
  1142135004 |Has presentation strength numerator value| = #500

Non-prescribable products

An Irish indicator reference set. Membership is curated by the release centre, so the subtype hierarchy plays no part.

^ 679971000220107 |Non prescribable indicator|

Oral products

Products whose manufactured dose form is oral, or any subtype of it. Note the attribute is Has manufactured dose form — the older name "Has dose form" still circulates but is out of date.

< 763158003 |Medicinal product| :
  411116001 |Has manufactured dose form| =
    << 385268001 |Oral dose form|

ECL syntax reference

Each card is a working query. Run it, then change one character and run it again.

Self

Match only the concept named

763158003 |Medicinal product|

Descendants

Everything beneath it, not itself

< 763158003 |Medicinal product|

Descendants or self

The concept plus everything beneath it

<< 763158003 |Medicinal product|

Children

One level down only

<! 763158003 |Medicinal product|

Ancestors

Everything above it

> 387517004 |Paracetamol|

Parents

One level up only

>! 387517004 |Paracetamol|

Member of

Concepts in a reference set

^ 660351000220100 |VTM reference set|

Any value

Has the attribute at all

< 763158003 |Medicinal product| :
  127489000 |Has active ingredient| = *

Attribute refinement

Filter by an attribute value

< 763158003 |Medicinal product| :
  411116001 |Has manufactured dose form| =
    << 385268001 |Oral dose form|

Multiple attributes

A comma means all must match

^ 660371000220109 |VMP reference set| :
  127489000 |Has active ingredient| = << 387517004 |Paracetamol|,
  411116001 |Has manufactured dose form| = << 385268001 |Oral dose form|

Conjunction

Must satisfy both sides

(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387517004 |Paracetamol|)
AND
(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387494007 |Codeine|)

Disjunction

Either side will do

(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387517004 |Paracetamol|)
OR
(< 763158003 |Medicinal product| :
   127489000 |Has active ingredient| = << 387207008 |Ibuprofen|)

Exclusion

Subtract one set from another

< 763158003 |Medicinal product|
MINUS
(< 763158003 |Medicinal product| :
  127489000 |Has active ingredient| =
    << 764146007 |Penicillin|)

Numeric value

Numbers use #

^ 660401000220107 |AMPP reference set| :
  1142142004 |Has pack size| = #24
