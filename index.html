What is ECL?

A formal way to describe a set of clinical concepts

A query language

ECL describes sets of SNOMED CT concepts using computable rules, so "all penicillins" becomes something a system can evaluate.

Hierarchy navigation

Move up and down the subtype hierarchy with <, > and their inclusive forms << and >>.

Attribute refinement

Narrow a set by what its members are made of — ingredients, dose forms, finding sites, pack sizes.

Curated lists

The ^ operator reads reference sets, which is how national release centres publish formularies and subsets.
